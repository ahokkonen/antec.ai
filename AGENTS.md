# AGENTS.md

Инструкции для любых AI-ассистентов и coding-агентов, работающих с этим репозиторием.
Файл не привязан к конкретному инструменту. Если инструмент не читает AGENTS.md сам,
его файл содержит только ссылку сюда и ничего больше. Например, `CLAUDE.md` для
Claude Code состоит из одной строки `@AGENTS.md` (импорт этого файла).

## О проекте

Модульная self-hosted AI-платформа на open source: агенты, чаты, MCP-инструменты,
аутентификация, авторизация, гардрейлы. Одна инсталляция на организацию,
ядро шаблонизировано, прикладная часть подключается плагинами.

Этот репозиторий: **ядро**. Инсталляции организаций (Mtech, клиенты) живут в отдельных
репозиториях `instance-<org>` и закрепляют версию ядра (ADR-0005). Клиентский код только
в плагинах; правки ядра под одного клиента запрещены.

Начинать чтение с `docs/README.md`.

## Обязательные правила

1. **Версии только из `policy/allowed-versions.yaml`.** Образы указываются как `image:tag@sha256:digest`.
   Плавающие теги (`latest`, `main`, `main-stable` и т.п.) запрещены. Новую версию сначала
   добавить в реестр через PR, потом использовать.
2. **Перед рекомендацией open source компонента** проверить актуальную версию, лицензию,
   активность и известные уязвимости по первоисточникам. Не полагаться на память модели.
3. **Лицензии.** Разрешены MIT, Apache-2.0, BSD-2-Clause, BSD-3-Clause, ISC, PSF-2.0, PostgreSQL.
   MPL-2.0 допустима без модификаций. Всё остальное (в том числе AGPL, SSPL, BSL, Elastic License,
   кастомные лицензии и open-core с платными ключевыми функциями) явно помечать и согласовывать
   (см. `docs/security/licensing.md`, ADR-0016).
4. **Заменяемость.** Внешний компонент используется только через стандартный протокол
   (OpenAI-совместимый API, MCP, OIDC/OAuth2, OpenTelemetry, SQL, S3) или через наш
   адаптер в `adapters/`. Импорт вендорских SDK вне `adapters/` запрещён.
5. **Безопасность.** Секреты только в хранилище секретов, никогда в коде, конфигах и `.env`
   в репозитории. Агент не получает прав больше, чем пользователь. Необратимые действия
   только с подтверждением человека. Каждый вызов модели и инструмента попадает в аудит.
6. **Архитектурные изменения** оформляются как ADR по шаблону `docs/adr/template.md`.
   Принятый ADR не переписывается: его заменяет новый ADR со ссылкой.

## Стиль

- Документы на русском, кратко. Без длинных тире (вместо них двоеточие, запятая или точка).
- Допущения помечать словом «Допущение», открытые вопросы выносить в раздел «Открытые вопросы».
- Код: Python 3.12+, полная типизация, FastAPI, Pydantic, pytest, uv, docker-compose.
  Уровень production, не демо.
- Markdown без инструмент-специфичных расширений. Диаграммы в Mermaid.
