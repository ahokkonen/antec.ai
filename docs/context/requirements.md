# Вводные и требования v1

Обновлено: 2026-11-24.

## Подтверждённые вводные

| Параметр | Значение |
| --- | --- |
| Модель поставки | Одна инсталляция на организацию (single-tenant). Ядро шаблонизировано, агенты, коннекторы, MCP, skills и каналы подключаются плагинами |
| Распространение | Сейчас только для Mtech. Далее Mtech хостит у себя отдельную инсталляцию для каждого клиента со своей конфигурацией и своими компонентами (например, Teams вместо Open WebUI). Кодовая база: ADR-0005 |
| Размер организации | До 500 пользователей на инсталляцию (расчётный максимум) |
| Сценарии | RAG-чат по документам; агенты с инструментами (Git, Slack, M365); coding-агенты; MCP |
| Каналы | Веб-чат (готовый, кастомизируемый), Telegram, Slack, API |
| Модели v1 | Облачные: OpenRouter, OpenAI, Anthropic |
| Локальные модели | Только в v2. Сервер без GPU |
| Данные в облачные модели | В v1 разрешены любые данные и любой код |
| M365 | Почта, календарь, OneDrive |
| Хранилище | PostgreSQL для всех прикладных данных. MongoDB не используем |
| Хостинг | Docker на своём сервере или в своём ЦОД. Компетенций Kubernetes нет |
| Идентификация | Entra ID; SCIM позже, но модель пользователей готова к нему |
| Команда | Около 10 человек, DevOps/SRE начинающие |
| Комплаенс | NIS2 обязательно; GDPR; EU AI Act (обязательства прозрачности по ст. 50 действуют с 2 августа 2026). Через платформу проходят данные разных классов |
| Выбор v1 | Чат-UI: Open WebUI. LLM-шлюз: LiteLLM. Оба легко заменяемы (ADR-0001, ADR-0002) |
| Версии | Только разрешённые версии без скомпрометированных релизов (ADR-0004) |

## Допущения

- Допущение: до 100 одновременно активных пользователей на инсталляцию.
- Допущение: хост MVP 8-16 vCPU, 32 GB RAM, SSD 500 GB, без GPU.
- Допущение: с облачными провайдерами заключены DPA; где возможно, включены режимы без
  хранения и без обучения на данных. Даже при разрешении «любые данные» это нужно для GDPR.
- Допущение: M365 подключается через Microsoft Graph с делегированными правами пользователя;
  отправка письма и создание события считаются необратимыми действиями и требуют подтверждения.
- Допущение: OneDrive в v1 используется через живые запросы Graph (права проверяет Microsoft),
  без индексации в наш RAG. Индексация OneDrive с синхронизацией ACL рассматривается в пилоте.
