# Бриф проекта

## Цель

Модульная корпоративная AI-платформа на open source без привязки к крупным экосистемам
(Microsoft, Google, AWS и т.п.). Дешёвая в эксплуатации, современная, легко адаптируемая
под разные компании и сценарии. Основной язык: Python.

## Части платформы

1. Центральное управление: пользователи, организации, модели, токены и бюджеты, метрики, логи, аудит
2. Агентная платформа: агенты, workflows, автоматизация процессов
3. Портфель MCP-серверов, инструментов и skills
4. Каналы и интерфейсы: веб-чат, API, мессенджеры, coding-агенты
5. Инструменты для разработки: код, тестирование, деплой

## Принципы

- Open source с разрешительными лицензиями (MIT, Apache-2.0, BSD, PostgreSQL, MPL-2.0). AGPL, SSPL,
  BSL, Elastic License, кастомные лицензии и open-core с платными ключевыми функциями явно помечаются
  (см. `docs/security/licensing.md`).
- Нет обязательной зависимости от одного вендора. M365, Google Workspace, Slack и др. только
  как опциональные адаптеры.
- Каждый компонент заменяем: за интерфейсом, адаптером или стандартным протоколом.
- Стандарты: OpenAI-совместимый API, MCP, OIDC/OAuth2, OpenTelemetry, SQL.
- Модели через собственный LLM-шлюз с переключением провайдеров без изменения кода.
- Единое хранилище чатов, истории и метрик, независимое от фронтенда.
- Docker / docker-compose в первую очередь, Kubernetes только при реальной необходимости.
- Простые проверенные решения (PostgreSQL + pgvector вместо отдельной векторной БД).
- Self-hosted, данные под нашим контролем, GDPR и EU AI Act.

## Требования безопасности

- Аутентификация: собственный OIDC-провайдер с федерацией с любым внешним IdP.
- Авторизация: права на уровне агентов, инструментов, данных и моделей; агент не получает
  больше прав, чем пользователь, от имени которого действует.
- Гардрейлы: фильтрация входа и выхода, защита от prompt injection, PII, подтверждение
  человеком для необратимых действий.
- Лимиты токенов и бюджета по пользователям и командам.
- Мультитенантность: изоляция на уровне отдельных инсталляций (ADR-0005); в модели данных
  сразу есть `org_id` и `team_id`.
- Секреты только в хранилище секретов.
- Полный аудит вызовов моделей и инструментов.
- Соответствие NIS2 (Финляндия: Kyberturvallisuuslaki 124/2025), GDPR и EU AI Act.
