## Состав MVP в docker-compose

Состав задаётся в репозитории инсталляции `instance-mtech`, образы ядра берутся из релиза репозитория `antec.ai` (ADR-0005). Версии и дайджесты только из `policy/allowed-versions.yaml`.

| Сервис | Компонент | Роль | RAM, ориентир |
| --- | --- | --- | --- |
| `proxy` | Caddy или Traefik | TLS, единая точка входа | 0,1 GB |
| `keycloak` | Keycloak | OIDC, федерация с Entra ID, MFA | 1,5 GB |
| `postgres` | PostgreSQL 18 + pgvector | Отдельные БД: keycloak, litellm, openwebui, platform, dbos | 4 GB |
| `openbao` | OpenBao | Секреты | 0,3 GB |
| `litellm` | LiteLLM | LLM-шлюз, ключи, бюджеты | 1 GB |
| `platform-api` | Свой FastAPI | Фасад, агенты, RAG, MCP-клиент, гардрейлы v1, аудит | 2 GB |
| `worker` | Тот же образ | Ingest документов (Docling), фоновые задачи | 4 GB |
| `cerbos` | Cerbos | Политики | 0,2 GB |
| `open-webui` | Open WebUI | Веб-чат | 1 GB |
| `mcp-m365` | Свой MCP-сервер | Почта, календарь, OneDrive через Graph | 0,3 GB |
| `mcp-git` | Свой MCP-сервер | GitHub или GitLab | 0,3 GB |
| `otel`, `victoria-metrics`, `victoria-logs`, `grafana` | Наблюдаемость | Метрики, логи, алерты | 2 GB |

Итого около 17 GB. Хост: 8-16 vCPU, 32 GB RAM, SSD 500 GB, без GPU. Эмбеддинги для RAG в v1
через облачную модель (разрешено вводными).
