# Плагины инсталляции

Код, нужный только этой инсталляции (ADR-0005, п. 3): MCP-серверы, адаптеры каналов. Каждый
плагин отдельный сервис со своим Dockerfile и работает вне процесса Platform API (ADR-0008, п. 1):

- MCP-сервер: Streamable HTTP, регистрируется в `mcp_servers` манифеста, токен пользователя
  получает обменом с аудиторией сервера (ADR-0007), секреты в OpenBao `antec/plugins/<name>`;
- канал: клиент OpenAI-совместимого фасада Platform API со своим OIDC-клиентом Keycloak
  (`settings.allowed_clients`).

Сервисы плагинов описываются в `compose.override.yaml`. Образы только по digest из реестра версий.

Адаптер канала (Teams, Telegram и др.) обязан до первого ответа сообщить пользователю, что он
общается с системой ИИ, и передавать метку `x-antec-ai-generated` дальше, где канал это позволяет
(AI Act, ст. 50; ADR-0015 ядра).
