## 1. Описание обработки (ст. 35(7)(a))

- Цели: ассистент и агенты для работы сотрудников; аудит для безопасности и комплаенса.
- Не цели: найм, оценка, мониторинг работы, решения о сотрудниках (ADR-0015, п. 2).
- Субъекты: сотрудники; люди, чьи данные сотрудники вводят или получают через инструменты.
- Данные: учётная запись (имя, email, id IdP), тексты сообщений, вызовы моделей и инструментов,
  аудит, данные инструментов (почта, календарь, файлы) по классам данных манифеста.
- Получатели: провайдеры моделей из манифеста (условия: ADR-0015, факты), MCP-серверы.
- Передачи вне ЕЭЗ: по провайдерам (SCC, DPF).
- Сроки: раздел `retention` манифеста (по умолчанию 90 дней тексты, 365 дней метаданные и аудит).
