# Работа с ИИ в __INSTANCE_NAME__

Правила для пользователей (AI Act, ст. 4: грамотность в ИИ).

- Ответы создаёт модель ИИ: они бывают неточными и выдуманными. Проверяйте факты, цифры, ссылки.
- Не принимайте с помощью ИИ решения о людях (найм, оценка, увольнение).
- Не вводите данные выше разрешённого класса (классы данных инсталляции).
- Агент выполняет действия только после вашего подтверждения: читайте, что подтверждаете.
- Письма, файлы и страницы могут содержать скрытые инструкции для ИИ: при странном поведении
  агента остановите его и сообщите в поддержку.
- Сгенерированный текст, публикуемый для информирования общественности, помечайте как созданный
  ИИ, если его не проверил редактор (AI Act, ст. 50(4)).
